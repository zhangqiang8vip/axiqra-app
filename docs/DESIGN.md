# Axiqra App 产品视觉与排版计划

## 1. 设计目标

为 **工程师 / AI 开发者** 打造的工具感产品：专业、高效、克制。不追求过度设计，在功能和审美之间取得平衡。

关键词：**工程感（Engineering）**、**精准（Precise）**、**克制（Minimal）**、**可信赖（Trustworthy）**

## 2. 视觉基调

### 2.2 字体

#### 主字体：`Inter`
- 无衬线，现代感，x-height 高，小号文字可读性好
- 适合 UI、数据密集型界面
- 字重：400（正文）、500（标签）、600（标题）、700（Logo）

#### 代码字体：`JetBrains Mono`
- 等宽字体，用于代码片段、Trace ID、API 路径、快捷键
- 14px，line-height 1.6

#### 字号体系
```
--text-xs:   12px  （辅助标签、小图标说明）
--text-sm:   14px  （正文、按钮、导航）
--text-base: 16px  （主要正文）
--text-lg:   18px  （小标题）
--text-xl:   20px  （中标题）
--text-2xl:  24px  （大标题 / 页面标题）
--text-3xl:  30px  （Hero 标题）
--text-4xl:  36px  （首页主标题）
```

#### 行高
```
正文：       1.5（--leading-normal）
紧凑标题：   1.25（--leading-tight）
说明文字：   1.625（--leading-relaxed）
```

### 2.3 间距体系

基于 4px 网格：
```
--space-1:  4px
--space-2:  8px
--space-3:  12px
--space-4:  16px
--space-5:  20px
--space-6:  24px
--space-8:  32px
--space-10: 40px
--space-12: 48px
--space-16: 64px
--space-20: 80px
--space-24: 96px
```

### 2.4 圆角

```
--radius-sm:  4px   （小标签、内联元素）
--radius-md:  6px   （按钮、输入框）
--radius-lg:  8px   （卡片、面板）
--radius-xl:  12px  （大卡片、模态框）
--radius-2xl: 16px  （特殊装饰）
--radius-full: 9999px（圆形按钮、Pill 标签）
```

### 2.5 阴影

```
--shadow-sm:  0 1px 2px rgba(0,0,0,0.05)        （悬浮提示、细微浮起）
--shadow-md:  0 4px 6px rgba(0,0,0,0.1)          （卡片悬浮、下拉菜单）
--shadow-lg:  0 10px 15px rgba(0,0,0,0.1)        （模态框、大卡片）
--shadow-xl:  0 20px 25px rgba(0,0,0,0.1)        （弹窗、浮层）
```

### 2.6 动效策略

克制动效，服务功能：
```
过渡时长：
  --transition-fast: 150ms  （悬停、状态切换）
  --transition-base: 200ms   （展开、收起）
  --transition-slow: 300ms   （页面切换、模态）

缓动函数：ease（default）、ease-out（出现）、ease-in-out（展开收起）

动效原则：
- 不做纯装饰性动画
- 搜索框聚焦、侧边栏展开、Tab 切换等场景使用动效
- 加载状态用骨架屏而非 Spinner
- 页面切换不做过场动画
```

## 3. 排版结构

### 3.1 布局容器

```
最大宽度：1280px
水平内边距：
  桌面（≥1024px）：24px
  平板（768-1023px）：20px
  移动（<768px）：16px
```

### 3.2 内容栅格

```
桌面：12 列，间距 24px
平板：8 列，间距 20px
移动：4 列，间距 16px

典型内容宽度：
  全宽（横跨 12 列）：搜索结果、列表
  窄宽（横跨 8-9 列）：详情页正文
  侧边+内容（3+9 列）：带侧边栏的页面
  三栏（4+4+4 列）：卡片列表
```

### 3.3 层级体系

```
一级：页面大标题（text-2xl，font-weight: 600）
二级：区块标题、卡片标题（text-xl，font-weight: 600）
三级：子区块标题、小标题（text-lg，font-weight: 500）
四级：标签、Tab（text-sm，font-weight: 500）
正文：内容文字（text-base，font-weight: 400，line-height: 1.5）
辅助：说明文字（text-sm，color: text-secondary）
```

### 3.4 内容节奏

```
页面内大区块间距：64px（--space-16）
区块内元素间距：24px（--space-6）
卡片内间距：20px（--space-5）
行内紧凑间距：8px（--space-2）
```

## 5. 图标规范

使用 **Lucide Icons**（MIT 许可，Vue 组件 `@lucide/vue-next`）：

- 统一 20px（导航）/ 16px（内嵌）两种尺寸
- 不混用填充和描边图标

## 7. 响应式断点

```
移动端：  < 768px   （手机）
平板：    768px+    （平板）
桌面：    1024px+   （笔记本 / 台式机）
宽屏：    1280px+   （大屏显示器）
```

---

## 8. 无障碍（a11y）

- 所有交互元素可键盘聚焦（:focus-visible）
- 颜色对比度 ≥ 4.5:1（正文）/ 3:1（大字）
- 语义化 HTML（button/header/nav/main/article）
- 隐藏内容使用 `.sr-only`
- 表单标签和错误提示关联
