# Axiqra Frontend

The web UI for Axiqra — Agent-ready engineering memory.

## Setup

```bash
npm install
npm run dev
```

## Tech Stack

Vue 3 + TypeScript + Vite + Tailwind CSS + Pinia + Vue I18n

## Features

- Dark/light theme with system preference detection
- Full internationalization (English / Chinese)
- Multi-color constellation starfield background
- Responsive design with mobile support
